# Changelog · 版本历史

> 按版本倒序排列，最新在最上；SKILL.md 只保留能力与规则说明，完整版本史以本文件为准。

## [1.1.3] - 2026-09-19

### 优化

- **版本历史迁出正文**：正文不再随版本累积历史表格，改由本文件维护。
- **描述字段改为单行写法**：原先的多行写法在部分解析器中只取首行，会让技能介绍被截断。

### 修复

- **脱敏字段口径对齐**：正文列明的脱敏字段与脚本声明的脱敏字段现在一致（均含「单位」）。

### 调整

- 发布包不再包含评测运行产物。

## [1.1.1] - 2026-09-06

### 修复

- 仓库与发布包中移除含个人健康数据的评测产物。

## [1.1.0] - 2026-08-29

### 新增

- **全部脚本支持 `--help`**，退出码统一为三态：`0` 成功 / `1` 运行期失败 / `2` 参数或前置条件不满足。
- **依赖自检** `check_deps.py`，执行流程第 0 步自动核对环境。
- **新年份报告接入不再改代码**：按年份硬编码的脚本合并为参数化 `extract.py --year`。
- **12 条触发词**与 **8 条回归评测**（含 3 条隐私防线用例）。

### 修复

- **隐私**：脱敏数据集改为「先在内存校验、通过后才写盘」——原先校验在写盘之后，命中身份信息时带 PII 的文件已落盘且只读，报错只是事后告警。
- **趋势分析漏项**：同一指标多次测量时只保留最新值的问题已修复。

## [1.0.3] - 2026-08-23
