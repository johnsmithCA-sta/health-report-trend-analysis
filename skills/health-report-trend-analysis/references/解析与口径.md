# 解析与口径参考（电子版 PDF）

> 供解析新格式报告时对照；坐标列边界基于某医院电子版 PDF（格式 A）实测。不同医院版式可能偏移，接入新格式前务必先做"小样本坐标确认"（见新报告接入指南）。

## 坐标列边界速查（格式 A）

基于 pymupdf `get_text("words")` 坐标，按 x 切列：

| 列 | x 范围 | 内容 |
|----|--------|------|
| 名称 | x < 195 | 检验项目名（如 `丙氨酸氨基转移酶(ALT)`） |
| 值 | 195 ≤ x < 295 | 结果数值（如 `51.0`） |
| 参考范围 | 295 ≤ x < 385 | 如 `9-50` / `<200` / `0.0-4.0` |
| 异常标志 | 385 ≤ x < 455 | `↑` / `↓` / `*` |
| 单位 | x ≥ 455 | 如 `U/L`、`mmol/L` |

**已知坑**：
- 名称与值 y 坐标可能差 0.5px → `group_lines` 用 y 容差 <1.5px 合并视觉行
- 参考范围 x=294.96 恰在 295 边界外 → ref 下限放宽到 290（以 295 为准，但注意 25-羟基维生素D 个案）
- 身体测量：名称 x<120 | 值 120-300；2023 是"值在前、名称在后"文本模式，需兼容
- 分组标题行（无值）作为 section，**跨页共享**（用 `shared_section[0]` 状态传递）

## 噪声过滤

- 页眉页脚：`美好人生`、`体检号`、`姓名`、`日期`、`第 X 页`、`体检报告书` 等
- 小结段落混入表格：如 `(1)乙型肝炎表面抗体...阳性(+)`、`8、....` → `is_dirty` 模式过滤

## 参考范围解析规则

| 写法 | 解析结果 |
|------|---------|
| `9-50` | lo=9, hi=50 |
| `<200` | lo=None, hi=200 |
| `>0.4` | lo=0.4, hi=None |
| `阴性/阳性` 等 | qualitative=True，不进数值序列 |

**正则顺序**：先匹配 `[<>]\s*[\d.]+` 再匹配 `[\d.]+\s*-\s*[\d.]+`（`-` 优先于 `<`，避免 `0-5.20` 被误拆）。

## 口径一致性原则

- **异常判定**：用**当年报告自带参考范围**（`e["ref"]`），不跨年套用统一范围——规避试剂/仪器差异（实例：直接胆红素 2025 年起 0.0–4.0 → 1.7–6.8）
- **显著变化**：相邻年相对变化 ≥20%，或绝对变化 ≥ 参考范围宽度 30%
- **趋势**：仅基于 `TREND_FOCUS_YEARS`（默认近三年 [2024,2025,2026]）；连续同向 = 持续升/降；先升后降/先降后升；否则波动
- **单位归一化**：`UNIT_MAP`（如 `mmol/l` → `mmol/L`、`umol/L` → `μmol/L`）

## 指标字典结构

`indicator_dict.py` 三部分：
1. `NAME_MAP`：146 个原始名 → 116 个标准名（含括号/缩写/别名归一）
2. `UNIT_MAP`：单位归一
3. `INDICATOR_META`：核心指标（30+）的临床意义 desc + 分层建议 advice（lifestyle/diet/exercise/see_doctor）

新增未收录指标：在 `NAME_MAP` 补一行映射；需要解读则补 `INDICATOR_META` 条目（引用默沙东诊疗手册/丁香医生/中国指南）。
