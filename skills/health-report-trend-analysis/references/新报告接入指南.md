# 新报告接入指南

> 目标：新增年度体检报告时，按本指南快速接入，避免重新踩坑（格式差异/字典缺失/OCR 参数）。
> 适用：任何年份的新报告，不限形态（电子版 PDF / 扫描件 PDF / 照片 JPG）。

---

## 0. 前置：识别输入形态

```bash
# 用 pymupdf 检查 PDF 是否有文本层
python3 -c "
import pymupdf, glob, os
for f in sorted(glob.glob(os.environ['REPORT_DIR'] + '/*.pdf')):
    doc = pymupdf.open(f)
    total = sum(len(doc[i].get_text()) for i in range(len(doc)))
    print(f'{os.path.basename(f)}: 页数={len(doc)} 文本层字符={total} -> {\"电子版\" if total > 200 else \"扫描件/照片\"}')
"
```

| 判定 | 后续流程 |
|------|---------|
| 文本层字符 > 200 | 电子版 → 走「分支 A」 |
| 无文本层 或 字符 ≤ 200 | 扫描件 → 走「分支 B」 |
| 年度目录 `YYYY体检报告/*.JPG` | 照片版 → 走「分支 C」 |

---

## 分支 A：电子版 PDF（推荐，最可靠）

### A1. 放置文件
PDF 放入 `REPORT_DIR` 根目录，命名建议 `体检报告_YYYYMMDD...pdf`（年份自动从登记日期识别，见 A3）。

### A2. 先小样本确认列边界（必做，降本纪律 1）
新医院/新版式务必先打印 1 页坐标样本，确认与 `references/解析与口径.md` 的列边界一致：

```bash
python3 -c "
import pymupdf
from collections import defaultdict
doc = pymupdf.open('<新PDF路径>')
page = doc[0]
# 找含化验表头的页
for i in range(len(doc)):
    if '检验项目' in doc[i].get_text():
        page = doc[i]; break
words = page.get_text('words')
lines = defaultdict(list)
for w in words:
    lines[round(w[1],1)].append((round(w[0],1), w[4]))
for y in sorted(lines)[:15]:
    print(round(y,1), sorted(lines[y], key=lambda t:t[0]))
"
```

- 列边界一致（名称<195 | 值195-295 | 参考295-385 | 标志385-455 | 单位≥455）→ 直接 A3
- 不一致 → 调整 `parse_reports.py` 中的列阈值（或按新格式写解析分支）

### A3. 解析
```bash
export REPORT_DIR=/path/to/体检报告目录
export WORK_DIR=/path/to/工作数据目录
$PY scripts/parse_reports.py
```

### A4. 检查解析质量
```bash
$PY -c "
import json
data = json.load(open(f'{os.environ[\"WORK_DIR\"]}/data/reports_raw.json'))
r = [x for x in data if x['year'] == <新年度>][0]
print(f'新年度指标数: {len(r[\"lab_items\"])}')
print('空值项:', sum(1 for it in r['lab_items'] if not it['value']))
print('无参考范围:', [it['name'] for it in r['lab_items'] if not it['reference']][:5])
"
```
- 指标数与往年相近（90±15）、无大段空值 → 通过
- 发现未识别/错位 → 按「问题排查」章节处理

## 分支 B：扫描件 PDF（无文本层）

### B1. OCR 提取
```bash
# 先单页验证 OCR 参数（降本纪律 1）
$PY scripts/vision_ocr.py <PDF路径> /tmp/ocr_test.json
# 查看输出，数字/参考范围识别正常则全量
$PY scripts/extract_2022.py   # 注意：该脚本路径写死了 2022，需按新年度调整 OCR_PATH 与 year 参数
```

### B2. 关键限制
- OCR 只提取 **15–20 个核心指标**（参考范围反推），精度有限
- 提取结果必须过 `PLAUSIBLE_RANGES` 合理性校验（`extract_2022.py` 内置）
- 被拒绝项在脚本输出中可见（如 `GGT -1.0`、`MCV 4.0`）

## 分支 C：照片版 JPG（手机拍摄）

### C1. 组织文件
```
$REPORT_DIR/2021体检报告/
├── 2021-1.JPG
├── 2021-2.JPG
└── ...
```

### C2. 合成 PDF + OCR
```bash
# 修改 make_year_pdfs.py 与 extract_2015_2020.py 中的年份列表，加入新年度
$PY scripts/make_year_pdfs.py
$PY scripts/extract_2015_2020.py
```
- 照片横拍（宽>高）自动顺时针旋转 90° 校正
- 中文项目名识别率低（<50%），依赖**英文缩写映射**（ALT/AST/TP/ALB 等）——新报告若来自不同医院，缩写可能不同，需在 `ABBR_MAP` 补充

---

## 3. 字典补录（所有分支通用）

解析日志会输出 `未识别指标名`（`build_dataset.py` 的 `unrecognized` 列表）。处理方式：

```python
# indicator_dict.py 的 NAME_MAP 追加一行：
"<原始名>": "<标准指标名>",
```

- 标准名尽量复用已有 116 指标（保持时间序列连续）
- 全新指标需补 `INDICATOR_META` 条目（desc 临床意义 + advice 分层建议），引用默沙东诊疗手册/丁香医生/中国指南

## 5. 验收清单

| 检查项 | 方法 | 通过标准 |
|--------|------|---------|
| 年份纳入 | `trend_analysis.json["years"]` | 包含新年度 |
| 数据点注入 | `dataset_std.json` 中该年 series 数 | 与解析指标数一致 |
| 图表显示 | 工作台时间轴 | 新年度出现，OCR 点灰色 Ⓞ |
| 数值抽查 | 随机 3 指标 vs 原始报告 | 一致（OCR 允许 ±1 尾数差） |
| 脱敏校验 | grep 姓名/证件号/电话/地址/医院 | 脱敏版零命中 |
| 字典覆盖 | 解析日志 `unrecognized` | 为空或已全部补录 |

## 问题排查速查表

| 症状 | 根因 | 解法 |
|------|------|------|
| 指标数骤减 | 列边界偏移（新医院版式） | A2 打印坐标，调整 parse_reports 列阈值 |
| 名称与值混在一格 | 名称/值 y 差 >1.5px 未合并 | group_lines 的 y 容差放宽到 2.0 |
| 参考范围粘连到值 | ref 列 x 边界偏移 | ref 下限放宽（如 295→290） |
| OCR 数值明显错误（负数/超大） | 数字串粘连或错位 | PLAUSIBLE_RANGES 已拦截，看拒绝日志 |
| 单位显示 μmol/L vs umol/L | 不同医院写法 | UNIT_MAP 补归一 |
| 报告/工作台年份不全 | `TREND_FOCUS_YEARS` 或 years 计算 | build_dataset 自动重算 years；趋势聚焦如需含新年份改 trend_analysis.py |
| 新年度未进趋势 | OCR 数据不参与判定 | 属预期：OCR 仅展示，电子版数据才参与 |
